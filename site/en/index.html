Features

Everything on the toolbar, just as it appears in the app

The toolbar buttons act on the whole class. Right-click a machine and the same action applies only to it. The interface is in Brazilian Portuguese: each feature below shows, in parentheses, the label you'll see in the app.

Power

Turn the lab on and off from afar. (Energia)

Shut down and Restart (Desligar, Reiniciar)

Shuts down or restarts the machines right away or with a 1- or 5-minute warning, and you can cancel. If you want, the pending Windows updates are installed along the way.

Makes it easy: at the end of the day, nobody has to go from machine to machine.

Turn on (Ligar)

Turns the machines on over the network (Wake-on-LAN).

Makes it easy: the lab is already starting up while the class walks in.

Schedule (Agendar)

Pick the days of the week and the times to turn on and shut down.

Makes it easy: the lab turns on before the first lesson and shuts itself down after the last.

Screen

See and take over any student's screen. (Tela)

View the screen (Ver a tela)

Opens a student's screen full size, live, with a double-click on their tile. The window takes the shape of the student's screen, the button bar hides by itself and Full screen (Tela Cheia) fills the whole monitor.

Makes it easy: you follow the activity without leaving your desk or standing behind the student.

Control (Controlar)

You use the student machine's keyboard and mouse; theirs are locked and the screen says the teacher is in control. The notice all but disappears when the mouse comes near it, so it doesn't hide what's underneath. Control keeps working when the administrator password prompt (UAC) appears and, with the lab's password saved, you fill it in with one click.

Makes it easy: sort out the question, the frozen program or the install that asks for a password from afar, without walking to the student's machine.

Lock screens (Bloquear telas)

Covers every screen with a padlock and locks keyboard and mouse until you unlock them. If a student presses Ctrl+Alt+Del, the Windows security screen closes by itself, and while it shows it offers no Task Manager, Sign out, Switch user, Lock, Change a password or power button.

Makes it easy: the class's attention comes back to you in one click, when it's time to explain.

Class

Talk to the class and exchange files. (Turma)

Message (Mensagem)

Shows a note on every student's screen.

Makes it easy: notices like "5 minutes left" reach everyone, without raising your voice.

Chat (Bate-papo)

Talks with the class; each student's reply reaches only you.

Makes it easy: a shy student can ask without exposing the question to the room.

Send file (Enviar arquivo)

Puts the file in the "Arquivos do professor" (teacher's files) folder on each student's desktop.

Makes it easy: no USB stick and no email: everyone gets the same material at the same time.

Collect files (Recolher arquivos)

Copies what each student put in the "Entregar ao professor" (hand in to the teacher) folder to your Documents\Midview\Recolhidos folder.

Makes it easy: the lesson's work arrives in one place, ready to grade.

Class folder (Pasta da turma)

Creates the lesson's class folder on each student's desktop. Whatever a student downloads or saves in it shows up on every computer. During the lesson, downloads from any program land in it, and Word, Excel, PowerPoint, Notepad and Paint open "Save as" right there. When the lesson ends, choose to keep the files, delete only today's or delete everything.

Makes it easy: students don't need to sit at the same machine to find last lesson's work.

Programs and websites

Open, install and clear away programs and websites. (Programas e sites)

Open website and Open program (Abrir site, Abrir programa)

Opens the same website or program on every machine, and up to 10 websites at once. The ones you use most stay saved in the menu.

Makes it easy: nobody mistypes the address and the activity starts together for everyone.

Install program (Instalar programa)

Installs a program on the whole class, as administrator, with no UAC screen and no password to type on each machine.

Makes it easy: a new program reaches the whole lab at once, without going machine by machine.

Uninstall program (Desinstalar programa)

Lists the programs installed on one machine and uninstalls the ones you choose across the class.

Makes it easy: remove what's no longer used from the lab, on every machine at once.

Close programs (Fechar programas)

Closes the open programs, with a warning and 30 seconds or 1 minute for the student to save, or right away.

Makes it easy: the end of the lesson stays tidy and the machines are ready for the next class.

Block programs (Bloquear programas)

Forbids the programs on a list, or lets only the ones you allow open.

Makes it easy: games and off-topic programs stay closed without you watching screen by screen.

Block websites (Bloquear sites)

Blocks the whole internet or only the websites you choose. The block stays even if the machine restarts.

Makes it easy: the class stays on task, exam days included.

Settings

Set the machines up once, for all of them. (Configurar)

Lab panel (Painel do laboratório)

Applies Chrome and Windows settings on every machine: ad blocker, guest mode, lock the taskbar, the desktop and downloads, and more. "RESET geral" (general reset) undoes it all.

Makes it easy: every machine is set up the same, without you visiting each one.

Classroom machines (Máquinas da sala)

Finds the machines on the network and pairs each one with you (checking within 5 minutes the code on the student's screen), gives a colleague access or joins their classroom, updates Midview on your computer and on the machines, and saves the lab's administrator password (only on this computer, protected by Windows) for remote control's "fill in the administrator password".

Makes it easy: when a new version comes out, Midview tells you as it opens and updates itself. On the machines, the update goes over the network, no USB stick: one tries the new version first and, if anything fails, goes back to the previous one on its own.

New

The school's phones and tablets on the same screen

Android phones and tablets (10 or newer) show up in the grid next to the computers. The Telas button shows all, computers, phones or tablets, and the toolbar works on them too: view and control the screen (with the student's touch locked), padlock, message, chat, send and collect files, class folder, open a website, install and close apps, turn the screen off and block apps, websites and the internet.

Prepared over a cable, in 1 minute

In Máquinas da sala > Configurar celular (or Configurar tablet), the assistant prepares each device over a USB cable, with pictures at every step. "Midview otimizado" removes the apps a class doesn't use, makes the device lighter and arranges the home screen; "Só o Midview" leaves the rest alone.

Locked the school's way

The student can't change the date, Wi-Fi, airplane mode or the wallpaper. Free Wi-Fi for a few minutes from Midview, or on the device itself with the administrator password. Set a PIN the student can't change and the wallpaper with the rules.

Find, update, give back

"Tocar para encontrar" rings the alarm at full volume. "Atualizar os celulares" and "Atualizar os tablets" send the new version over the network. "Tirar o Midview" undoes everything and uninstalls, or resets to factory.

And more

The details that make a difference in class

Right-click a machine

The toolbar actions work on a single student too. There you'll also find Talk (Conversar), to chat with just that student, Uninstall program, Edit the machine and Remove from the classroom list.

The grid your way

"Show all" (Visualizar todos) fits every screen without scrolling, "Online only" (Só online) hides the machines that are off and the slider (or Ctrl + mouse wheel) changes the size of the screens. With "Arrange room" (Organizar sala), drag the screens until they match how the machines sit in the room; "Align" (Alinhar) straightens everything.

More than one teacher

"Give a colleague access" (Dar acesso a um colega...) creates a code valid for 10 minutes. The colleague types it in "Join a colleague's classroom" (Entrar na sala de um colega...) and sees the same machines. Or use "Allow a new teacher" (Permitir novo professor): for 10 minutes, the machines accept another teacher's pairing. With two teacher computers, the class folder works on both.

Getting started

In four steps, the lab is on your screen

  1. Download the installer

    The same MidviewSetup.exe works for your computer and for the machines. Nothing else to install.

  2. Install it on your computer

    Choose Professor (teacher). The "Midview - Sala de aula" shortcut appears on the desktop. If the "Windows protected your PC" screen appears, click More info and then Run anyway.

  3. Install it on the machines

    On each lab machine, choose Aluno (student).

  4. Bring in the machines

    In Midview, click Máquinas da sala > Procurar e parear > Procurar na rede (search the network) and pair them, checking the 6-digit code shown on the student's screen (you have 5 minutes to do it).

Pair the machines right after installing: until the first pairing, any teacher on the network can pair them. Whoever looks after IT can install many machines at once with MidviewSetup.exe /VERYSILENT /SUPPRESSMSGBOXES /TIPO=aluno.

Privacy and requirements

Everything stays inside the school

Privacy

  • Lesson data doesn't leave the school. Midview sends nothing to the developer. Only your computer uses the internet, to fetch Midview updates from GitHub.
  • Protected communication. Screens, commands and files travel encrypted, and each machine only accepts the teachers paired with it.
  • Tell the class. A student's screen can be viewed with no notice on their machine; only remote control shows a notice. The school must inform students and their parents or guardians, as data protection laws such as Brazil's LGPD require.
  • Administrator password only on your PC. If saved, it stays only on the teacher's computer, protected by Windows, and is never sent to the students' machines.

Requirements

  • 64-bit Windows 10 or 11 on your computer and on the machines.
  • The same local network for the teacher and the lab.
  • Windows administrator only at install time.
  • Internet only on your computer, to receive Midview updates.
  • To turn machines on over the network, Wake-on-LAN enabled in the machines' BIOS and network card.
